# UCS (Upvote Consulting Services) -- ML & Backend Engineer Intern

**Duration:** May 2025 -- July 2025

## Overview

During my internship at **Upvote Consulting Services (UCS)**, I worked
on building secure AI-powered backend systems and improving enterprise
document retrieval using Retrieval-Augmented Generation (RAG). My work
focused on optimizing semantic search performance and developing
production-ready backend APIs with modern authentication mechanisms.

## Responsibilities

### 1. RAG-Based Document Search Optimization

**Problem** - Enterprise document search across 1,000+ files was slow
and often returned low-relevance results.

**Solution** - Designed and implemented a Retrieval-Augmented Generation
(RAG) pipeline. - Optimized the **Milvus** vector database indexing
strategy. - Improved semantic document retrieval for enterprise
knowledge bases.

**Impact** - Reduced retrieval latency by **65%**. - Improved response
relevance by **40%**.

### 2. Secure Backend API Development

**Problem** - Enterprise AI services required secure authentication
before client deployment.

**Solution** - Built REST APIs from scratch. - Implemented **JWT
Authentication**. - Added **OAuth2** authentication support. -
Integrated **rate limiting** to protect APIs from abuse.

**Outcome** - Delivered secure, production-ready backend services
suitable for enterprise deployment.
